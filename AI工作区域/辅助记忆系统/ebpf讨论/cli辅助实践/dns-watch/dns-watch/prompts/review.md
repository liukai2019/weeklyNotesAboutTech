Review the current dns-watch v0 idea critically.

I do not want encouragement first.
I want pressure-testing first.

Please challenge the current v0 from these angles:
- user value
- scope discipline
- technical realism
- WSL2 practicality
- observability usefulness
- risk of misleading output
- risk of building something impressive but not actually useful

Please do the following:

1. State what part of the current idea is genuinely strong.
2. State what part is still weak or vague.
3. Ask 10-15 hard questions that would expose weak assumptions.
4. Identify 3-5 ways v0 could fail while still looking “successful”.
5. Identify what should probably be removed from v0 if we become stricter.
6. Rewrite the v0 problem statement in a sharper way.
7. Decide whether the current v0 should:
   - proceed now
   - narrow scope first
   - gather evidence first

Important rules:
- Be critical, concrete, and practical.
- Do not mainly propose new features.
- Focus on whether the current v0 is believable and useful.
- If the brief and spec are misaligned, call it out.
- Prefer one sharp recommendation over broad commentary.

Use this output structure:

## Strong parts
## Weak or vague parts
## Hard questions
## Ways this could fail while looking successful
## What should be cut if we tighten v0
## Sharper v0 problem statement
## Recommendation
